# PLMS 运维手册

> 适用场景：Docker Desktop 重启 / 宿主机重启后恢复 PLMS 全栈服务。

---

## 前置条件

- [ ] Docker Desktop 已启动，引擎状态正常（系统托盘鲸鱼图标不转圈）
- [ ] 终端在项目根目录 `C:\Users\Win10\WorkBuddy\2026-07-17-10-48-16\plms` 下

验证 Docker：

```bash
docker info > /dev/null && echo "Docker OK" || echo "请先启动 Docker Desktop"
```

---

## 快速恢复（3 步）

### 1. 启动 PostgreSQL

```bash
docker start plms-postgres
```

等待就绪（约 3 秒）：

```bash
docker exec plms-postgres pg_isready -U plms -d plms
# 输出: /var/run/postgresql:5432 - accepting connections
```

### 2. 启动后端

```bash
npx tsx apps/backend/src/index.ts
```

看到 `🚀 PLMS Backend 已启动: http://localhost:3000` 即成功。

### 3. 启动前端

```bash
npx vite --host 0.0.0.0 apps/frontend
```

看到 `Local: http://localhost:5173/` 即成功。

## 特殊情况处理

### 情况 A：Docker Desktop 重置导致容器丢失

如果 `docker start plms-postgres` 报错找不到容器，说明 Docker Desktop 做了静默重置（WSL 磁盘重建），需要从头恢复：

```bash
# 1. 检查镜像是否存在，若不存在则通过代理拉取
docker pull docker.1ms.run/library/postgres:16-alpine
docker tag docker.1ms.run/library/postgres:16-alpine postgres:16-alpine

# 2. 创建并启动 PostgreSQL 容器
docker run -d --name plms-postgres \
  -e POSTGRES_USER=plms \
  -e POSTGRES_PASSWORD=plms_pass_2026 \
  -e POSTGRES_DB=plms \
  -e TZ=Asia/Shanghai \
  -p 5432:5432 \
  --restart unless-stopped \
  postgres:16-alpine

# 3. 等待就绪
sleep 5

# 4. 运行数据库迁移和种子数据
npx prisma migrate deploy --schema=apps/backend/prisma/schema.prisma
npx tsx apps/backend/prisma/seed.ts

# 5. 回到"快速恢复"步骤 2、3
```

> **提示**：`--restart unless-stopped` 可以让容器在 Docker Desktop 重启后自动启动，减少手动操作。

### 情况 B：端口被占用

```bash
# 查看端口占用
netstat -ano | grep -E ":(3000|5173)\s"

# 强杀占用进程（谨慎使用）
taskkill //F //PID <进程ID>
```

### 情况 C：登录报错"用户名或密码错误"

说明种子数据丢失，重新播种即可：

```bash
npx tsx apps/backend/prisma/seed.ts
```

## 项目目录结构

```
plms/
├── apps/
│   ├── backend/          # Express + Prisma 后端
│   │   ├── prisma/       # 数据库 schema + 种子数据
│   │   └── src/
│   │       └── modules/  # 业务模块 (auth/users/projects/tasks...)
│   └── frontend/         # Vue 3 + Element Plus 前端
│       └── src/
│           └── views/    # 页面组件
├── packages/shared/      # 共享类型/枚举/常量

└── docs/                 # 文档
```
